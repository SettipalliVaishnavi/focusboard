# AI Usage Documentation – FocusBoard

## AI Tool Used
**ChatGPT**

## How I Used ChatGPT

During the development of FocusBoard, I used ChatGPT as a learning and problem-solving assistant.

I worked on the project step by step and used ChatGPT whenever I had doubts or faced difficulties during implementation.

### 1. Understanding Requirements
I asked ChatGPT to clarify some project requirements and explain how different features should work, such as task management, status filters, priority filters, dashboard statistics, and localStorage.

### 2. Clarifying Technical Doubts
Whenever I had doubts about React components, props, state management, React Hooks, and JavaScript functionality, I asked ChatGPT for simple explanations and examples.

### 3. Resolving Errors
During development, I encountered some errors and issues while setting up the project and implementing features. I shared the error messages and asked ChatGPT to explain the possible causes and suggest solutions.

### 4. Understanding Difficult Implementation Parts
For challenging parts such as connecting multiple React components, implementing combined filters, updating task statistics dynamically, and saving task data in localStorage, I used ChatGPT to understand the implementation step by step.

### 5. Responsive Design Guidance
I asked ChatGPT for guidance on CSS styling and responsive layouts to make the dashboard suitable for desktop, tablet, and mobile screens.

### 6. Documentation Support
I used ChatGPT to organize and prepare the README.md and AI_USAGE.md documentation.

## My Contribution

- I set up the React and Vite project.
- I worked on implementing and connecting the application components.
- I ran the application locally and checked its functionality.
- I tested task creation, editing, deletion, searching, filtering, status updates, and localStorage persistence.
- I reviewed and verified the production build.

## Conclusion

ChatGPT was used mainly to clarify doubts, understand difficult concepts, troubleshoot errors, and improve my development process. I actively worked on the implementation, ran the application, and tested the features.

AI assistance was used as a supporting learning tool throughout the project development process.
